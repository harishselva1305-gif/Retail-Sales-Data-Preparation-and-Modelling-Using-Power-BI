Power BI – Data Preparation & Modelling

PROJECT OVERVIEW
This project focuses on data preparation and data modelling using Microsoft Power BI. It covers importing data from multiple sources, cleaning and transforming data using Power Query, creating relationships, and building a structured data model for business analysis.

OBJECTIVES
- Import data from Excel, CSV, and SQL databases.
- Understand ETL (Extract, Transform, Load) basics.
- Clean and transform data using Power Query Editor.
- Handle missing values and duplicate records.
- Create relationships between tables.
- Understand Fact Tables and Dimension Tables.
- Build a Star Schema data model.
- Create and manage a Date Table.

TOOLS & TECHNOLOGIES
- Microsoft Power BI Desktop
- Power Query Editor
- Microsoft Excel
- CSV Files
- SQL Database

KEY CONCEPTS

1. DATA IMPORT
Import datasets from:
- Excel files
- CSV files
- SQL databases

2. POWER QUERY & ETL
- Extract data from different sources.
- Transform and clean raw data.
- Load prepared data into Power BI.

3. DATA CLEANING & TRANSFORMATION
- Remove duplicates.
- Handle missing values.
- Change data types.
- Rename columns.
- Filter unwanted records.
- Standardize data.
- Merge and append queries.

4. DATA RELATIONSHIPS
- One-to-many relationships.
- Primary keys and foreign keys.
- Relationship cardinality.
- Cross-filter direction.

5. DATA MODELLING
- Fact Tables.
- Dimension Tables.
- Star Schema.
- Snowflake Schema basics.

6. FACT & DIMENSION TABLES

Fact Table:
Stores transactional and numerical data such as sales, quantity, revenue, and profit.

Dimension Tables:
Stores descriptive data such as customer, product, store, region, and date details.

7. STAR SCHEMA
Create a star schema using a central fact table connected to dimension tables.

Example:
- Fact_Sales
- Dim_Customer
- Dim_Product
- Dim_Store
- Dim_Date

8. DATE TABLE
Create a calendar table containing:
- Date
- Year
- Quarter
- Month
- Month Number
- Week
- Day
- Day Name
